# Demo verification checklist

1. `npm install`
2. `npm run build` — must finish without errors.
3. `npm run dev`
4. Try Demo Mode.
5. Enter a real public GitHub username and click Roast My GitHub.
6. Confirm profile, score, roast, repositories, tech stack, activity, fixes and rescue plan render.
7. Open View on GitHub links.
8. Try an invalid username to verify the friendly error.
9. Try an empty username to verify validation.
10. If GitHub rate-limits the browser, use Demo Mode or configure `VITE_GITHUB_TOKEN` in `.env.local`.
